# Steering Squad branding and interactive sections

## Goal
Bring the homepage closer to the uploaded visual references while preserving the existing premium black-and-red direction.

## Changes
- Replace the drawn Steering Squad mark in the header and footer with the uploaded official logo, and derive the favicon from it.
- Match the uploaded typography more closely with a tall, condensed display face for headlines and compact automotive labels, while keeping body copy readable.
- Expand “Start With Your Vehicle” into an interactive fitment experience: selections update a live vehicle profile with the chosen year, make, model, trim, compatibility status, and next-step guidance.
- Restyle “Built Around You” to match the updated uploaded reference, including the carbon texture, stronger numbered columns, refined spacing, and icon treatment.
- Make “Make It Yours” meaningfully interactive: selecting each customization option updates the active specification, descriptive copy, preview counter, visible callouts, and wheel preview treatment.
- Keep all changes responsive, including the stacked vehicle profile and customization controls on mobile.

## Technical details
- Store the uploaded logo through the project asset flow and use a small optimized copy for the browser icon.
- Keep interaction state local to the homepage; no account or database is required.
- Preserve existing page links and all other homepage sections.
- Verify the updated header, vehicle finder, trust section, and customizer on desktop and mobile.
