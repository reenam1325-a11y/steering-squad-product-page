# Steering Squad Homepage Rebuild

## Goal
Create an original, premium homepage that moves visitors from vehicle selection to a custom steering wheel request or purchase, while establishing Steering Squad as a global automotive craftsmanship brand.

## Experience
- Lead with cinematic steering-wheel imagery, a direct build action, and concise global-build trust messaging.
- Make vehicle discovery the first major section after the opening image, using a clear make → model → year → trim flow.
- Keep the journey visible through repeated, contextual actions: find a vehicle, view a build, customize, or request help.
- Use a compact sticky desktop navigation with a vehicle mega-menu, plus a persistent mobile build action.

## Homepage Structure
1. Announcement bar and responsive navigation
2. Cinematic opening section
3. Prominent interactive vehicle finder
4. Craftsmanship and fitment proof points
5. Masonry featured-build gallery with lightbox
6. Configurator-style customization showcase
7. Four-step build process
8. Clickable vehicle-brand directory
9. Draggable factory-to-custom comparison
10. Custom vehicle request section
11. Replaceable customer review examples
12. Visual social gallery
13. Functional FAQ accordion
14. Dramatic final action and detailed footer

## Visual Direction
- Deep black and charcoal foundation with white typography, restrained light gray, and a precise red accent.
- Large editorial automotive type, compact technical labels, subtle corners, and carbon-inspired surface texture.
- Product-led photography with close steering-wheel crops; no generic lifestyle stock or placeholder blocks.
- Fast fade reveals, image zooms, sticky-header compression, selector transitions, and reduced-motion support.

## Technical Details
- Implement as the root TanStack page with reusable, focused React sections.
- Define all visual values as semantic design tokens in the global stylesheet.
- Generate and bundle a cohesive set of steering-wheel imagery for the opening, gallery, configurator, comparison, social grid, and final action.
- Implement local interactive behavior for navigation, selectors, lightbox, comparison control, accordions, and mobile menu; external shopping destinations remain presentation-only until product URLs or commerce data are supplied.
- Add unique homepage title, description, Open Graph fields, and social card metadata.
- Validate the rendered page at desktop and mobile widths, including interaction states and overlap checks.
